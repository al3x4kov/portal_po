# Эпик E5 — Импорт/экспорт архивов

Ценность: перенос проекта целиком, round-trip без потерь. Трассировка: FR-3, FR-10;
NFR-4 (атомарность).

---

## T-501 · Экспорт в архив (zip + tar.gz) · [M] · параллельно: да
- **Что:** `ArchiveRepo.export(projectDir, format)` → поток `.zip` (archiver) или
  `.tar.gz` (tar).
- **Где:** `apps/server/src/lib/archive.ts`.
- **Критерии приёмки:**
  - [ ] Экспортируется полный набор `.md` + манифест.
  - [ ] Поддержаны оба формата; имя файла-архива корректное.
- **Тесты (Vitest, temp dir):** создать проект → экспорт → распаковать → состав совпадает.
- **Зависимости:** blocked by: T-302 · blocks: T-503, T-504.
- **Трассировка:** FR-10.

## T-502 · Импорт архива с валидацией и атомарностью · [M] · параллельно: да
- **Что:** `ArchiveRepo.import(archive, name)`: распаковать во `Projects/.import-tmp/<rand>`,
  валидировать схему всех `.md` и целостность ссылок, затем атомарно `rename` в проект.
- **Где:** `apps/server/src/lib/archive.ts`, `services/ProjectService.ts`.
- **Критерии приёмки:**
  - [ ] Битый/неполный архив → ошибка, целевой каталог не создаётся, tmp удалён (FR-3.4).
  - [ ] `Projects/` воссоздаётся при отсутствии (FR-3.2).
  - [ ] Дубликат имени → `409`.
- **Тесты (Vitest, temp dir):** валидный импорт; битый архив (откат); дубликат; traversal в архиве.
- **Зависимости:** blocked by: T-202, T-302 · blocks: T-503, T-504.
- **Трассировка:** FR-3, NFR-4, NFR-5.

## T-503 · API импорта/экспорта · [S] · параллельно: да
- **Что:** `POST /api/projects/import` (multipart), `GET /api/projects/:id/export?format=`.
- **Где:** `apps/server/src/routes/archive.ts`.
- **Критерии приёмки:**
  - [ ] Загрузка архива и скачивание архива работают; форматы валидируются.
  - [ ] Ошибки импорта возвращают понятные коды/сообщения.
- **Тесты (Vitest/integration):** импорт ок/битый; экспорт zip и tar.gz.
- **Зависимости:** blocked by: T-501, T-502, T-301 · blocks: T-504, T-603, T-607.
- **Трассировка:** FR-3, FR-10.

## T-504 · Playwright: round-trip экспорт→импорт · [S] · параллельно: да
- **Что:** E2E: создать проект с требованиями и связями → экспорт → импорт под новым
  именем → состав и связи идентичны (DoD#3).
- **Где:** `e2e/import-export.spec.ts`.
- **Критерии приёмки:**
  - [ ] Round-trip без потери требований и связей.
  - [ ] Импорт битого архива показывает ошибку в UI.
- **Тесты:** Playwright.
- **Зависимости:** blocked by: T-503, T-603, T-607 · blocks: —.
- **Трассировка:** FR-3, FR-10, DoD#3.
