## Соглашения по разработке (для всех задач)
- TypeScript strict, ESLint+Prettier зелёные.
- **Unit-тесты (Vitest)** обязательны для каждой задачи в `packages/core` и `apps/server`
  (логика). **Playwright E2E** — для пользовательских сценариев (отмечено в задачах).
- Каждая задача мерджится только при зелёном `lint + typecheck + unit` (и `e2e`, где есть).
- Запись на диск — атомарна; все пути — строго внутри `Projects/` (NFR-4, NFR-5).
- Definition of Done — см. раздел 6 ТЗ.
