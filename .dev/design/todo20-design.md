## Решения

- Токены — общие с приложением (`docs/design/tokens.css` скопирован в `tokens.css`),
  темы light/dark через класс `dark` на `<html>`, кнопка-переключатель на каждом экране.
- Модалка — один каркас на все состояния (заголовок с проектом/моделью, статус-бейдж,
  контент, нижний ряд действий) — прямая проекция на существующий `AiImportModal`.
- Шаги «1. Смета → 2. Извлечение → 3. Итог» — лёгкий степпер только там, где есть выбор
  (смета); прогресс/ошибка/итог живут в том же диалоге без степпера.
- В UI «чанк» называем «фрагмент» — без жаргона (E1); в логе события — человеческие
  формулировки деградаций, тех.детали только в сворачиваемом блоке и файле лога.
- Ошибка: первая строка — что случилось; затем «что сделать»; счётчики «ничего не потеряно»;
  действия ранжированы: «Продолжить» (primary) → «Повторить с меньшими фрагментами» → «Открыть
  частичный результат».
- Отчёт: таблица покрытия по классам источников + блок «Обратите внимание» (слепые зоны) —
  прямо из E4.
