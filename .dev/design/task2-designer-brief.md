# Бриф дизайнеру — экран «Формат выгрузки» + примеры содержания (Task 2)

Полный контекст: `.dev/design/task2-export-content-spec.md`. Компонент: `apps/web/src/components/ExportModal.tsx`
(шаг `format`, заголовок «Формат выгрузки»). Токены — существующие `var(--color-*)`; визуальный язык
согласовать с именованными группами фильтров из Task 1.

## Что нарисовать на экране «Формат выгрузки»
Над карточками форматов — блок «Данные для выгрузки» из 2 именованных групп:

1. **Группа «Обязательные данные»** — 3 чекбокса `checked + disabled` (залочены): Название,
   Критичность, Статус реализации. Визуально: замок/приглушение, тултип «Всегда включается в выгрузку».
2. **Группа «Дополнительные данные»** — 4 переключаемых чекбокса: Источник требования, Описание,
   Справочная информация, Связи. Дефолт — все включены.

Сохранить существующее: 3 карточки форматов (Excel .xlsx / .zip / .tar.gz), счётчик «Выбрано N
требований», кнопки «← Назад» / «Отменить».

**Превью-подсказка** (динамическая по выбору): строка/панель «В выгрузку войдут: колонки Excel …;
секции OpenSpec …». Показать и вид для крайнего случая (сняты все опциональные).

## Состояния (галерея)
- Чекбокс: залоченный (disabled+checked), опциональный вкл, опциональный выкл, hover.
- Тема: light и dark.
- Экран целиком: дефолт (всё вкл) и минимум (все опциональные сняты).

## Примеры содержания файлов (статичные снимки на макете)
- **Excel**: (A) все колонки: `Требование | Тип | Критичность | Реализация | Источник | Описание |
  Справочная информация | Связи`; (B) минимум: `Требование | Тип | Критичность | Реализация`.
  Показать заливку критичности и отступ по дереву; «Справочная информация» — многострочная ячейка
  `«тип: значение»`.
- **OpenSpec .md**: (A) полный (заголовок + метки + описание + `#### Links` + `#### Info`);
  (B) минимум (заголовок + `criticality` + `implemented` [+`target`]).
