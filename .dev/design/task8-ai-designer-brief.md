# Бриф дизайнеру — AI Hub (Task 8)

Полный контекст: `.dev/design/task8-ai-feature-spec.md`. Приложение — React + Vite + Tailwind,
токены `var(--color-*)` (см. `apps/web/src/index.css`), тема light/dark. Визуальный язык —
как существующие экраны (Sidebar, Dashboard, RequirementModal). Заголовки групп — `text-xs
uppercase`, `var(--color-text-3)`.

## Экран 1 — «AI» (маршрут /p/:id/ai)
Слева — фиксированный `Sidebar` (добавляется иконка «AI», активное состояние). Контент —
**2 колонки** (на узком экране — стек):

**Левая колонка «Подключение к AI Hub»** (форма):
- поле «API-ключ» — тип password, маска `••••`, кнопка-глаз показать/скрыть; строка-статус
  «ключ сохранён» / пусто;
- поле «Base URL» — дефолт `https://api.ai.sbt/openai/v1`;
- кнопка «Сохранить и загрузить модели»;
- «Модель» — выпадающий список (`<select>`); показать также вариант ручного ввода `model id`
  (fallback, когда список не загружен);
- строка статуса подключения: успех (зелёный, «загружено N моделей») и ошибка (красный, текст);
- пустое состояние: ключ не задан → подсказка «Введите API-ключ, чтобы загрузить модели».

**Правая колонка «Инструкция»** — нумерованные шаги (1 Авторизация → 2 API-ключ → 3 Base URL →
4 Список моделей → 5 Первый запрос), ссылка на `https://hub.ai.sbt/` (внешняя, новая вкладка).
Опционально — сворачиваемый блок «Пример кода (Node.js)» моноширинным шрифтом (справочно).

Состояния экрана: пусто (нет ключа), загрузка моделей, успех (список моделей + выбрана модель),
ошибка подключения. Light и dark.

## Экран 2 — Кнопка «AI Hub generation» в форме требования
В `RequirementModal` рядом с полем «Описание» — кнопка «AI Hub generation» (иконка-искра).
Показать поток состояний:
1. свернуто: только кнопка у поля «Описание»;
2. раскрыто: поле «Уточняющая подсказка» (textarea, необязательно) + кнопка «Сгенерировать»;
3. загрузка: спиннер;
4. превью: карточка с полученным описанием (read-only) + кнопки «Отменить» / «Применить» /
   «Сгенерировать заново»;
5. ошибка: читабельное сообщение, поле «Описание» не меняется;
6. состояние «не настроено»: кнопка задизейблена + тултип-ссылка «Настройте AI Hub» → /ai.
«Применить» добавляет текст в конец описания с новой строки (показать до/после).
