# task23 — Сворачивание отдельного узла дерева ФТ/НФТ в режиме «Развернуть все» (пилотный баг №2)

## Проблема

Кнопка (шеврон) у узла дерева ФТ/НФТ не сворачивает ветку, пока пользователь не
нажмёт «Свернуть все». Ожидание пользователя: шеврон работает всегда.

## Причина

`apps/web/src/store/ui.ts`: `treeMode: 'expand-all' | 'collapse'`, дефолт
`expand-all`; множество `expanded` учитывается только в режиме `collapse`.
`apps/web/src/pages/Main.tsx:432,450`: `interactiveChevron={collapsed}` — в
режиме expand-all шеврон декоративный.

## Что сделать

1. Сделать шеврон интерактивным в обоих режимах:
   - в режиме `expand-all` клик по шеврону сворачивает конкретную ветку
     (локальное исключение из «всё развёрнуто»);
   - повторный клик разворачивает обратно;
   - в режиме `collapse` поведение как сейчас (раскрытие из `expanded`).
2. Рекомендуемая модель состояния (согласовать с текущим кодом
   `store/ui.ts` + `lib/visibility.ts`): хранить множество исключений-переопределений
   (например `collapsedOverrides` для expand-all), либо унифицировать в одну
   модель «expanded set + режим по умолчанию». Выбрать вариант с минимальным
   диффом и понятной семантикой; computeVisibleRows должен учитывать оба режима.
3. Кнопки «Развернуть все» / «Свернуть все» сбрасывают точечные переопределения
   (после них дерево в чистом состоянии соответствующего режима).
4. Поиск/фильтры: текущее поведение принудительного раскрытия совпадений при
   поиске не ломать.
5. Доступность: шеврон остаётся кнопкой с aria-атрибутами (aria-expanded).

## Критерии приёмки

- Свежая загрузка (режим по умолчанию expand-all): клик по шеврону любой ветки
  сворачивает её; клик снова — разворачивает.
- «Свернуть все» → всё свёрнуто; точечные раскрытия работают (как раньше).
- «Развернуть все» → всё развёрнуто, ранее свёрнутые вручную ветки снова видны.
- Компонентные тесты (Vitest) на новую логику visibility/store; существующие
  тесты TreeTable зелёные (обновить, если менялась семантика).

## Ограничения

- Менять только apps/web (+ его тесты). Контракты/сервер не трогать.
- Начать с `graphify query`, закончить `graphify update .`.
