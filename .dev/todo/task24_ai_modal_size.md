# task24 — Модалка «AI-импорт документации»: ~70% экрана (пилот todo_22 №1)

## Проблема

Модальное окно «AI-импорт документации» (`apps/web/src/components/AiImportModal.tsx`)
занимает ~30% экрана — узкое и низкое. После todo_20 в нём живут смета с описью,
прогресс с лентой событий, отчёт качества с таблицей, история джоб — всем тесно,
таблицы переносятся, журнал 170px со скроллом.

## Что сделать

1. На десктопе модалка занимает ~70% вьюпорта по ширине И высоте
   (ориентир: `width: min(70vw, …)`, `height: 70vh` или эквивалент через
   max-w/max-h; конкретные классы выбери по текущей реализации Modal/AiImportModal).
2. Внутренняя раскладка использует добавленную высоту: журнал анализа/лента событий
   и таблица отчёта растягиваются (flex-колонка, лог получает основной остаток
   высоты вместо фиксированных 170px; минимальная высота сохраняется).
3. На узких экранах (<~768px) поведение как сейчас (почти полная ширина), без
   горизонтального скролла.
4. Другие модалки приложения (RequirementModal, ExportModal и т.д.) НЕ трогать:
   если размер задаётся общим Modal — добавь вариант размера (проп), не меняй дефолт.
5. Скроллинг: контент модалки скроллится внутри, шапка и ряд действий закреплены.

## Критерии приёмки

- Десктоп 1280×800: модалка ≥65% и ≤80% ширины и высоты вьюпорта на всех шагах
  (setup/смета/прогресс/ошибка/отчёт).
- Журнал анализа занимает свободную высоту (заметно больше 170px на 800px-экране),
  aria/role сохранены (role="log", tabIndex).
- Мобильная ширина 375px: без регресса и без горизонтального скролла.
- Существующие компонентные тесты зелёные; на изменение размера — тест на проп/классы.

## Ограничения

- Владение: только apps/web/src (+тесты). Контракты/сервер/e2e не трогать.
- Начать с `graphify query`, закончить `graphify update .`.
