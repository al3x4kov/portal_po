# T2 — Входные экраны: Start, NewProject, Import, OpenExisting

Читай сначала: .dev/todo/task17_common.md, макеты new_design/screens/{start,new-project,import,open-existing}.html.
Код: apps/web/src/pages/{Start,NewProject,Import,OpenExisting}.tsx (+тесты рядом).

## Start (макет start.html)
- Hero-карточки основных действий, блок «Недавние проекты», компактные сервисы — по макету.
- «Недавние проекты»: localStorage (ключ вида po.recentProjects, массив {id,name,openedAt}, максимум как в макете); записывать при открытии/создании/импорте проекта; клик — открыть проект; если пусто — состояние из макета.

## NewProject (new-project.html)
- autofocus на поле имени; hint по символам/длине; busy «Создаём…»; success-состояние.
- ТЕКСТ: «Будет создан проект:» (НЕ «Будет создан каталог:»).

## Import (import.html)
- Состояние dragover у дропзоны; автоимя проекта из имени архива (клиент, редактируемо); индикатор прогресса импорта.

## OpenExisting (open-existing.html)
- Фильтр-поиск по списку; удаление проекта с подтверждением вводом имени (уровень 2); ошибка удаления показывается внутри диалога, не глотается.

## Приёмка
- Все состояния макетов воспроизведены (пустое/загрузка/ошибка/успех/busy).
- Средний род для «требование» во всех текстах.
- Компонентные тесты обновлены/добавлены (recent projects из localStorage, автоимя из файла, фильтр, confirm вводом имени).
