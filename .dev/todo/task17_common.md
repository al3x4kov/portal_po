1. `graphify query "<вопрос>"` / `graphify explain "<концепт>"` — СНАЧАЛА, потом читать файлы.

## Сквозные требования к текстам (PO)
- Слово «требование» — СРЕДНИЙ род: «оно моё», «выбрано», «удалено», «создано», «Показано X из Y».
  Проверить ВСЕ новые и существующие тексты затрагиваемых экранов на «она моя» → «оно моё».
- Все тексты UI на русском; идентификаторы/код на английском.
- Минимальный кегль текста 11px (`--text-min`), включая чипы/метки/оси.

## Решения PO по [ОТКРЫТО] из DESIGN.md (без новых контрактов)
- «Недавние проекты» на Start: хранить в localStorage (пишем при открытии/создании проекта), API не трогаем.
- Undo в toast «Сохранено»: НЕ делаем (нет endpoint). Сохранение редактирования без confirm + обычный toast «Сохранено».
- Автоимя проекта при импорте: на клиенте из имени файла архива (обрезать расширение, заменить недопустимые символы на «_», предзаполнить поле, редактируемо).
- Markdown в DescPanel: безопасный рендер без сырого HTML (react-markdown без rehype-raw ИЛИ существующий рендерер из ChatWidget, если он есть — переиспользовать).
- «Граф» в Sidebar: пункт навигации, который включает существующий режим графа (без нового маршрута).
- Порядок типов связи в LinkModal — как в макете.

## Стек и паттерны
- Иконки: Lucide inline-SVG 18/20 stroke-2 (как в макетах). Допустимо добавить dep `lucide-react`; смысл не кодируется только цветом.
- Toast: позиционируется НАД FAB чата (`--toast-offset: 88px`); error-toast живёт 8 с, пауза таймера по hover.
- Busy-кнопки: спиннер + герундий («Создаём…», «Сохраняем…»), disabled на время запроса.
- Row-actions: видимы всегда приглушённо, полная видимость hover/focus-within, на touch — всегда (класс .row-actions из tokens.css).
- Фокус: :focus-visible outline 2px primary.
- data-testid: сохранить существующие где элемент остаётся; новые — по образцу существующих; в конце работы выдать список добавленных/изменённых testid.
