# Task 1 — Именованные группы фильтров + кейс-инсенситивный «Источник»

**Файл:** `apps/web/src/components/RequirementPickerModal.tsx`
Это ОБЩИЙ компонент двух экранов:
- «Выбор требований для экспорта» (через `ExportModal`)
- «Выбор ФТ/НФТ для TaskTracker» (через `ExportTasksModal`)

Правка одного компонента чинит оба экрана. Бэкенд НЕ трогаем (это Task 2).

## Контекст (как сейчас)
Зона фильтров (`data-testid="export-filter-zone"`) — единый блок с одним заголовком «Фильтры».
Внутри подряд, без разбивки: чипы критичности, кнопки реализации (Все/Реализовано/Запланировано),
чипы источника (когда `availableSources.length > 1`), чипы кварталов (когда выбрано «Запланировано»).
Ниже отдельной строкой без заголовка — «Выбрать все / Снять выделение» + счётчик «N из M выбрано».

## AC (a) — разбить фильтры на ИМЕНОВАННЫЕ группы
Каждая группа со своим мелким заголовком (стиль текущего «Фильтры»: `text-xs font-semibold uppercase tracking-wide`, `color: var(--color-text-3)`):
1. **«Критичность»** — чипы критичности (`CRITICALITIES`), testid `export-filter-crit-*`.
2. **«Реализация»** — кнопки Все/Реализовано/Запланировано (`export-filter-impl-*`); чипы кварталов
   (`export-filter-q-*`) остаются внутри/под этой группой при выбранном «Запланировано».
3. **«Источник»** — чипы источников (`export-filter-src-*`). Группу показывать только когда различных
   источников ≥ 2 (как сейчас; с учётом нормализации из пункта b).
4. **Отдельная именованная группа для выбора** (заголовок, напр. «Выбор») — вынести сюда
   «Выбрать все» / «Снять выделение» (`export-toggle-all`) + счётчик «N из M выбрано».

Требования к разметке:
- СОХРАНИТЬ все существующие `data-testid`: `export-filter-zone`, `export-filter-crit-*`,
  `export-filter-impl-*`, `export-filter-src-*`, `export-filter-q-*`, `export-toggle-all`.
- Заголовки групп — семантично (можно `role`/подпись); визуально согласовать с дизайн-токенами.
- Группы визуально разделены (отступы/разделители), читаемо в light/dark.

## AC (b) — «Источник» кейс-инсенситивно
Значения источника, отличающиеся только регистром (напр. `АС21` и `ас21`), считаются ОДНИМ значением.
- `availableSources`: группировать по `(source ?? '').trim().toLowerCase()`; для чипа показывать
  канонический ярлык (первое встретившееся оригинальное написание непустого источника).
- `passesFilters`: сравнивать `(r.source ?? '').trim().toLowerCase()` с нормализованным выбранным значением.
- `sourceFilter` хранить в нормализованном (lowercase) виде.
- «Не задан» (пустой источник) — поведение и позицию (в конец) сохранить.
