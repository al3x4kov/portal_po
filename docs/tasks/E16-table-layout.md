# E16 — Раскладка таблицы: колонка «Связи», ширина действий, полноэкранный режим, проверка перекрытий

Основание: фидбек PO. Проблемы:
1. Кнопки действий «+ НФТ», «Связать», «Удалить» перекрывают границы карточек секций
   (колонка действий `w-[150px]` мала для 3 кнопок → контент вылезает влево/за край).
2. Области ФТ/НФТ не используют всю ширину экрана (`max-width: 1600px`).
3. Нужна отдельная колонка **«Связи»** (сейчас чипы связей висят под названием).
4. Автотесты должны проверять видимость и отсутствие перекрытий элементов.

## Новая раскладка таблицы (FE, обе секции ФТ и НФТ, `table-fixed`)
Колонки по порядку:
1. **Требование** — только название (+ отступ дерева, чип раскрытия, метка «предок»).
   **Убрать** блок чипов связей из этой колонки.
2. **Критичность** — 130px.
3. **Реализация** — 140px.
4. **Связи** — НОВАЯ колонка. Рендерит НЕиерархические чипы связей
   (`RELATES_TO`/`DEPENDS_ON`/`BLOCKED_BY`) — те же, что были под названием (с переносом,
   `data-testid="rel-chip-<src>-<tgt>"`, `data-rel-type`). Пусто — «—». Гибкая ширина (~20%).
   Ячейка: `req-links-cell`.
5. **Описание** — гибкая (остаток), truncate с «…».
6. **Действия** — ширина достаточна для 3 кнопок (напр. `w-[210px]`), `whitespace-nowrap`,
   `justify-end`, без переполнения/клиппинга. Кнопки: `row-add-nfr` (только ФТ),
   `link-btn-<slug>`, `delete-btn-<slug>`.

Шапка: добавить `th` «Связи» между «Реализация» и «Описание».

## Полноэкранный режим (FE, `pages/Main.tsx`)
- Убрать ограничение `max-width: 1600px` у `<main>` → использовать всю ширину экрана
  (`w-full` + горизонтальные отступы `px-4`). Секции ФТ/НФТ занимают всю ширину.

## Инвариант «без перекрытий»
- Контент любой ячейки не выходит за пределы карточки секции по горизонтали
  (`overflow-x-auto` обёртки таблицы сохраняется как страховка, но при штатной ширине скролла
  быть не должно). Кнопки действий целиком внутри своей ячейки и карточки.

## Автотесты видимости/перекрытий (QA, Playwright) — T-1601
Для секций ФТ и НФТ:
- Навести на строку → кнопки `row-add-nfr` (у ФТ), `link-btn-*`, `delete-btn-*` **видимы**
  (`toBeVisible`) и их bounding box **целиком внутри** bounding box карточки секции
  (левая/правая границы кнопок в пределах карточки; кнопки не налезают друг на друга).
- Чипы связей находятся в колонке «Связи» (в пределах ячейки `req-links-cell`), не перекрывают
  соседние колонки.
- Общий инвариант: `document.scrollingElement.scrollWidth ≈ clientWidth` (нет горизонтального
  выхода страницы за экран) на ширинах 1280 и 1680.

## Unit (FE)
- `TreeTable.test`: чипы связей теперь в ячейке «Связи» (`req-links-cell`), а не под названием;
  колонка присутствует в обеих секциях; действия содержат до 3 кнопок; existing testid целы.
