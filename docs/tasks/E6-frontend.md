Ценность: рабочий UI по макетам `docs/design/`. React+Vite+TS+Tailwind, токены из `docs/design/tokens.css`.
Трассировка: FR-1…FR-10; NFR-6, NFR-7. После T-601 экраны делаются параллельно.

## T-601 · Каркас web + API-клиент · [M] · параллельно: нет (база эпика)
- **Что:** Vite+React+TS+Tailwind; перенос дизайн-токенов из `docs/design/tokens.css` в
  `tailwind.config`; React Query + Zustand; типизированный API-клиент (типы из core/zod).
- **Где:** `apps/web/src/{api,store,main.tsx}`, `tailwind.config.ts`.
- **Критерии приёмки:**
  - [ ] Приложение собирается и открывается; тема light/dark переключается.
  - [ ] API-клиент типизирован, ошибки сервера обрабатываются единообразно.
- **Тесты:** компонентный smoke (Vitest + Testing Library) рендера корня.
- **Зависимости:** blocked by: T-101 · blocks: T-602…T-607.
- **Трассировка:** NFR-1, NFR-6.

## T-603 · Экраны New / Import / Open · [M] · параллельно: да
- **Что:** формы нового проекта (с проверкой имени), импорта (dropzone+имя), списка проектов.
- **Где:** `pages/NewProject.tsx`, `Import.tsx`, `OpenExisting.tsx`.
- **Критерии приёмки:**
  - [ ] New: блокирует занятое имя (по ответу API), показывает Main Path после создания.
  - [ ] Import: принимает zip/tar.gz, показывает ошибку битого архива.
  - [ ] Open: рендерит список из `GET /projects`, открывает основной экран.
- **Тесты:** компонентные (валидация, состояния ошибки) + участвуют в T-305/T-504.
- **Зависимости:** blocked by: T-601, T-304, T-503 · blocks: T-305, T-504.
- **Трассировка:** FR-2, FR-3, FR-4.

## T-606 · Модалки связывания и подтверждения · [M] · параллельно: да

- **Критерии приёмки:**

  - [ ] Удаление требует подтверждения; деструктив-стиль.
- **Тесты:** компонентные (поиск, формулировка, отображение ошибки, подтверждение).
- **Зависимости:** blocked by: T-601, T-404, T-405 · blocks: T-406.
- **Трассировка:** FR-8, FR-9; NFR-7.
