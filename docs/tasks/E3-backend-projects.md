## T-301 · Каркас Fastify-сервера · [M] · параллельно: нет (база эпика)
- **Что:** сборка Fastify (плагины, единый error-handler, pino-логгер), раздача
  собранного фронта, конфиг порта/пути к `Projects/`.
- **Где:** `apps/server/src/app.ts`, `main.ts`, `lib/logger.ts`.
- **Критерии приёмки:**
  - [ ] Сервер стартует, `/healthz` отвечает 200.
  - [ ] Доменные ошибки маппятся в JSON `{code,message,details}` и коды 400/404/409/422/500.
  - [ ] Логируются запросы и ошибки.
- **Тесты (Vitest/integration):** healthz; маппинг ошибки в нужный код.
- **Зависимости:** blocked by: T-101 · blocks: T-303, T-304, E4, E5.
- **Трассировка:** §3.3 arch, NFR-9.

## T-302 · ФС-утилиты: pathSafe + atomicWrite · [M] · параллельно: да

- **Где:** `apps/server/src/lib/`.
- **Критерии приёмки:**
  - [ ] Любой путь вне `Projects/` отклоняется (`..`, абсолютные, символьные).
  - [ ] Запись атомарна: при сбое не остаётся частичного файла.
- **Тесты (Vitest):** traversal-кейсы; имитация сбоя записи; конкурентная запись.
- **Зависимости:** blocked by: T-101 · blocks: T-303, T-401, E5.
- **Трассировка:** NFR-4, NFR-5.

## T-303 · Проекты: репозиторий и сервис · [M] · параллельно: да
- **Что:** `FsProjectRepo` + `ProjectService`: список каталогов `Projects/`, создание
  проекта (с **воссозданием** `Projects/`, если отсутствует), чтение манифеста/Main Path.
- **Где:** `apps/server/src/repositories/FsProjectRepo.ts`, `services/ProjectService.ts`.
- **Критерии приёмки:**
  - [ ] `Projects/` воссоздаётся, если удалён (FR-2.3).
  - [ ] Дубликат имени проекта → `409 Conflict` (FR-2.5).
  - [ ] Имя каталога санируется (NFR-5).
  - [ ] Возвращается Main Path созданного/открытого проекта (FR-5.1).
- **Тесты (Vitest, temp dir):** воссоздание, дубликат, санитизация, список.
- **Зависимости:** blocked by: T-301, T-302 · blocks: T-304.
- **Трассировка:** FR-2, FR-4.
