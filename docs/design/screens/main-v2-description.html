B4 · Описание — боковая панель (drawer)

← В галерею

В таблице описание — одна строка с усечением (…). Клик по ячейке или её тексту открывает правую панель с полным описанием (Markdown, до 5000 символов), не теряя контекст таблицы. Панель прокручивается и содержит быстрые действия.

Сохранение карты (токенизация)

Платежи / Оплата картой

PCI-DSS токенизация карточных данных: вместо реального номера карты (PAN) в системе хранится token, полученный от токен-провайдера. Это снижает область соответствия PCI-DSS.

Правила

  • PAN не сохраняется ни в БД, ни в логах.
  • Токен привязан к покупателю и мерчанту.
  • Поворот ключей шифрования — раз в 90 дней.

Сценарии

WHEN покупатель отмечает «запомнить карту», THEN система запрашивает токен и сохраняет его вместо PAN. WHEN токен-провайдер недоступен, THEN оплата проходит без сохранения карты (graceful degradation).

Ограничение по хранению — до 5000 символов, поддерживается Markdown-разметка.
