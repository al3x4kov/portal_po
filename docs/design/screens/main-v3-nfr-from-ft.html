← В галерею

В строке ФТ появляется компактное действие «+ НФТ» (рядом со «Связать»/«Удалить»). По клику открывается модалка создания НФТ с плашкой о предустановленной связи: ФТ BLOCKED_BY новое НФТ. После сохранения НФТ появляется в своей секции и сразу связано с этой ФТ.
