§1 · Поле «Источник требования» — в форме RequirementModal

Combobox (input + datalist) — позволяет выбрать пресет или ввести произвольное значение. Располагается в блоке основных атрибутов, в одной строке с «Критичность» (на маленьких экранах — отдельная строка). Пресеты: «АС21», «ПАО». Показаны три состояния.

data-testid="req-source-input" · value="МойИсточник" · нет outline — просто текст

UX-детали: Поле — нативный <input list="…"> (combobox). Datalist содержит пресеты; пользователь может ввести любое значение. Пустое поле = «Не задан» (null в модели). При совпадении с пресетом — показать тихую индикацию «Пресет распознан» (цвет primary). Произвольное значение не подсвечивается ошибкой. Поле необязательное — нет звёздочки.

§2 · Колонка «Источник» в TreeTable (только режим Дерево)

Колонка вставляется между «Критичность» и «Связи». Ширина ~130px. В режиме Граф колонка скрыта. Три варианта отображения: «—» (не задан), пресет «АС21», кастомное «МойИсточник».

Сохранение карты (токенизация) High АС21 Q3 2026 —

Варианты отображения: — = не задан (null) АС21 = пресет (primary-soft фон) МойИсточник = кастомное (surface-2 фон)
Поведение: Колонка «Источник» (width=130px) показывается только когда активен режим Дерево. В режиме Граф — скрыта (display:none). Пресетные значения (совпадающие с предустановленным списком) рендерятся тегом с indigo-фоном; произвольные — серым тегом. null/пустая строка → тире «—».

§3 · Фильтр «Источник» — в TreeToolbar

Кнопка «Источник» встаёт рядом с «Критичность» и «Реализация» — аналогичный стиль btn-secondary. Дропдаун: мультиселект с чекбоксами, в том числе «Не задан». Показаны два состояния тулбара: без активных фильтров и с активным фильтром (бейдж «1»).

Тулбар — фильтр активен + открытый дропдаун
Источник требования
Показано 3 из 11 · по источнику
Поведение: Кнопка активна (border primary, text primary, бейдж-счётчик) когда хотя бы один вариант выбран. В дропдауне кастомные значения собираются из реально встречающихся в дереве (динамический список). Пресеты идут первыми в алфавитном порядке, кастомные — ниже с пометкой «кастом». data-testid для каждого значения: source-opt-{slug}.

UX-детали: Поле «Тип» — maxlength=50, поле «Значение» — maxlength=100. При нажатии ✓ (ref-info-confirm-btn) — пара добавляется в список, форма скрывается. При нажатии ✕ в форме — форма скрывается без сохранения. При нажатии ✕ рядом с парой — строка переходит в inline-confirm (пара подсвечивается красным, кнопки «Да»/«Нет»). Кнопка «Применить» модалки заблокирована в состоянии ожидания подтверждения.
