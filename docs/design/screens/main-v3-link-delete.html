У каждой связи — кнопка-корзина. По клику строка переходит в инлайн-подтверждение (маленькое, как у удаления требования): текст + «Отменить»/«Удалить». Подтверждение удаляет реципрокную пару (useDeleteLink). Отмена ничего не меняет.
