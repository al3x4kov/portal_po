# Матрица ситуаций «корректно / некорректно» (A4, исх. 10)

Каждая строка → автотест. Тип: **U** unit (`@po/core`/server), **E** e2e (Playwright).
Владелец: BE (unit/интеграция), QA (e2e).

## Хранилище / парсинг OpenSpec
| # | Ситуация | Ожидание | Тип |
|---|----------|----------|-----|
| S1 | serialize→parse требования (round-trip) | без потерь (все поля, сценарии, links) | U |
| S2 | Файл с `implemented:false` без target | ParseError (правило 2.4) | U |
| S3 | Файл с `implemented:true` + target | ParseError (target запрещён) | U |
| S4 | Битый заголовок (нет `### Requirement:`) | ParseError, не краш; файл помечен broken | U |
| S5 | Описание >5000 симв | ошибка валидации | U |
| S6 | Сценарий без WHEN/THEN | сохраняется, но флаг «неполный сценарий» (warn) | U |

## Slug / уникальность
| # | Ситуация | Ожидание | Тип |
|---|----------|----------|-----|
| S7 | Два ФТ с именами, дающими один slug | второй получает `-2` | U |
| S8 | Дубль имени в одном типе (case-insensitive) | отклонить (uniqueness) | U/E |
| S9 | Одинаковое имя в разных типах (FUNCTION/NFR) | разрешить | U |
| S10 | Переименование `name` | slug/файл не меняются, связи целы | U |

## Целостность связей
| # | Ситуация | Ожидание | Тип |
|---|----------|----------|-----|
| S11 | Self-link | отклонить | U |
| S12 | Цикл PARENT_OF/CHILD_OF | отклонить | U |
| S13 | Второй родитель | отклонить (один родитель) | U |
| S14 | Удаление требования | каскадная чистка обратных ссылок | U/E |
| S15 | Удаление узла с потомками | запрет + подсказка (FR-9.3) | E |
| S16 | Связь на несуществующий slug | отклонить (нет висячих) | U |

## Импорт / экспорт
| # | Ситуация | Ожидание | Тип |
|---|----------|----------|-----|
| S17 | Экспорт zip → импорт | round-trip идентичен | E |
| S18 | Экспорт `.xlsx` | валидный xlsx (PK-заголовок), лист Requirements/Links непустые | U/E |
| S19 | Импорт xlsx | не поддержан (ясная ошибка/скрыт в UI) | E |
| S20 | Экспорт tar.gz | round-trip | E |

## ФС-безопасность
| # | Ситуация | Ожидание | Тип |
|---|----------|----------|-----|
| S21 | slug/имя проекта с `../` или сепаратором | отклонить (pathSafe, NFR-5) | U |
| S22 | Имя проекта с запрещёнными символами ОС | отклонить | U/E |
| S23 | Отсутствует `Projects/` | автосоздаётся | U/E |
